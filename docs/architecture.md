# 英文论文 PDF 中文翻译 Skill · 首版架构

2026-11-24，agy 主拟，负责人选定连续分页（1B）和保留原图并就近给中文对照（2A）。Codex 实现，按实际译页向 agy 反馈。

## 使用时会发生什么

在 Codex 中给出英文 PDF，当前会话负责翻译。目标交付是一份能够独立阅读全文的简体中文 PDF。正文、图表题、脚注和附录均纳入盘点。表头、图例和图像内标签按 2A 处理，就近给出中文。作者名、模型名、数据集名、指标标识、公式、数值、单位和 DOI 按学术惯例保留。参考文献保留可检索的原始书目，可按需另附中文题名。正式学术术语首次出现时给出中文与英文或原有缩写，后面统一用词。翻译须简洁，同时保全比较对象、否定、条件、量值和不确定性。

| 环节 | 职责 | 可核查的结果 |
| --- | --- | --- |
| 1. 读版面 | 识别页、栏、阅读顺序、段落、图表和公式。把原页渲染出来，核对文本层读不到的内容。 | `inventory.json` 保存原文件指纹、源页、文本块和坐标。`translation.json` 记录阅读顺序、译文和关联编号，能将相邻页的残句关联到完整译文。 |
| 2. 定术语 | 根据题名、摘要及全文用法建立本篇术语表，标记应原样保留的专名和符号。 | `SAR` 首次出现可写作「合成孔径雷达（SAR）」，`DETR`、`mIoU` 等名称可追溯至原文。 |
| 3. Codex 翻译 | 按完整句和段落翻译，再将译文关联回原位置。遇到公式、引用或表格，保留它们与文字的对应关系。 | 每个应译项都有中文及对应来源。批量应用专名和符号的保留规则，仅对例外记录理由。 |
| 4. 检查是否译全 | 对账各项内容，核查数值、单位、公式标记及关键语义。图像内文字须有视觉盘点，单靠英文字符计数不能判断是否译全。 | 缺译、疑似错列、模糊图像标签进入待处理清单，处理前不报整篇完成。 |
| 5. 写回并复核 | 在原栏宽内用中文折行，保护影像、图线、公式和表格数值。渲染中文页，对照原页复核，修正后重新出图。 | `translated.pdf` 为阅读成果。页图和 `qa.json` 为开发验收证据；中文译文必须在这一份 PDF 内读得到。 |

开发时由 agy 拟方案并根据证据复核，Codex 负责实现、翻译和测试。日常使用 Skill 时由当前 Codex 完成翻译，无需用户另配翻译 API。[Skill 入口与使用流程](../skills/translate-paper-zh/SKILL.md)。

## 跨学科和跨刊物

所有英文论文 PDF 共用同一入口。版式逐页判断。原生文本层、足够长且并列的行、跨栏长行、图片覆盖及纸幅方向给出初步提示。已有清单中的人工栏数和经过核对的区域优先。正文旁的出版信息、横向附表、扫描页和多栏小字应回到原页分区核对，必要时按一栏或两栏顺读。判定图像和文字属于同一研究问题时，翻译、图注和短批仍在同一张纸上交付。

手记跟随该段论证。数学研究追量词、假设和证明步骤；实地研究追采样单位和统计比较；软件论文追输入、算法、输出与验证；综述及定性研究追材料选择、推论和适用边界。每份交付根据相应原文、选页范围与实际核验注明完成程度。[各类 Agent 共用的精读方法](../skills/translate-paper-zh/references/reading-voice.md)

## 底层工具怎样选

首轮以四篇论文的相同选页比较了两条路线。BabelDOC 衍生实现能将待译任务直接交给当前 Agent，擅长保持原公式，发布时校验页数与原文相同。PyMuPDF 路线由 Codex 核对原段落和图表区域，支持原位排版、就近续排与复杂页重排。十页实测与同文图表字号对照后，agy 建议选择后者作为个人试用的主路线，保留前者作为固定版式参照。两者的自动化程度、页码规则和所需人工判断不同。[现成的 Agent 对接实现](https://github.com/JiaJunDeng5930/PDF-translate-skill) · [BabelDOC 上游](https://github.com/funstory-ai/BabelDOC) · [本项目复核结论](iterations.md)

## 负责人确认的阅读体验

1. **连续阅读（1B）。** 当准确、精简的中文仍然超出原栏，沿阅读顺序排至邻栏或紧随的译页。页底标注原页码。尽量把变化限制在发生溢出的原页或区段，后文可恢复自己的原版式。
2. **保住原图，图旁配中文（2A）。** 图像、曲线、颜色和表格数值保持原貌。将有语义的英文标签、窄格表头配上中文，放在同一份 PDF 里与图表相邻的位置。图表与对应中文组成一个排版单元。图片表也要核对每列和每行。

agy 的三级准则依次为原位回填（L0）、保留能原位容纳的前段并就近续排（L1）、复杂页按语义单元重排（L2）。原位排版试用 100%、95%、90%、85% 四档名义字号。实测表格说明在 6–7 磅时阅读吃力，因此原型另外给实质性中文设 8 磅下限，页脚单独处理。此数值是开发起点，可随样本和读者反馈调整。

## 首轮实现工单

用 10 张源页比较两种实现，包括 SkySense 第 1–3 页、DETR 第 5–6 页、GenCD 第 1–2 页及 SPGAN-DA 第 10–12 页。两种路线的输入译文一致；记录运行版本、命令和源页编号。

按页列出应译项和实际覆盖，记录遗漏、乱码、错误阅读顺序、公式损坏、溢出与表格错列。对照原页与译页渲染图，核查数字和单位、否定与条件、公式及视觉标签。提取阶段盘点到的内容和视觉巡检中的内容合并核算。重要语义由 Codex 对照原句审阅，程序校验编号和数值。任一路线如无法接入当前 Codex 或持续破坏公式，可提前结束其试验并保留失败证据。

每轮先查本文件与[迭代记录](iterations.md)。Codex 将复现步骤、逐页结果、对照页图和失败归因交回 agy，记录 agy 的意见及下一工单。只有经负责人确定的产品取舍才升为规则。10 页小样只用于选引擎和发现问题，整篇验收还要另跑完整论文。

## 整篇验收

合册后用同一个原文指纹一次生成全文，逐页核对纸张尺寸、实际落位、源文本块和可见译文。检查从正文进入书目、从书目进入附录的位置，并在图版插入时核对前后残句。书目带中文题名时，按原编号逐项对应，并从成品抽取保留的原始著录，确认读者能复制和搜索。裁切图表及窄栏后，也要检查图框外的源文是否混入复制结果。

遇到作者图注与可见面板冲突时，保留足以还原作者说法的文字，在同一图旁用「译注」指出具体差异。若正文表格的数值、单位或适用范围与附录不同，分别按当地上下文翻译，并标出原文位置。一次整篇测试只记录该版本和版式下实际通过的项目。

负责人已确认作者判断和技术词须保持原文的含义与具体程度。若准确表述所需的篇幅超出原框，保留限制条件，沿阅读顺序续排。交付前结合源块逐句核对结论强弱、比较、因果、量词及技术实现。完整规则和 Open-Canopy 正反例见 [Skill 的翻译与核对要求](../skills/translate-paper-zh/SKILL.md#翻译并核对)。

## 精读手稿

默认交付一份带手记的卡其纸中文 PDF。底本在翻译排版时铺浅卡其色 `#FAF3E3`，正文用霞鹜文楷。底色在原图、图例、色标、表格和公式的裁片处镂空，保留原图透明区域的混合效果。核对时先将无笔迹底本对照原页，再检查成品上的圈线与高亮是否遮住图例、坐标刻度、数值或上下标。

短句用悠哉（Yozai）写在译文锚点附近的空白，英文短词用 Caveat，数字和易混标识用正体。可以圈一格误差、在式旁代入一组数，或在模型段旁画出输入到输出的步骤。空间有限时，把较长的观察、疑问或设想放进右侧页边。全册统一扩边，红蓝墨用于圈写，浅黄用于高亮。选点疏密由论文内容决定，整页或整节均可留白。[Open-Canopy 第 4 页实样](reading-notes/Open-Canopy-khaki-p04.png)

由当前 Agent 对着原文和附录选点。先还原作者的研究思路，再从关键实验反查模型、基线、公式和原始文献，沿途在最容易误读的地方落笔。已有模块指回原著，本文的适配指回方法节，特定改动的效果优先查消融。读者自己的延伸设想用假设语气写。各 Agent 通过[仓库入口](../AGENTS.md)使用同一份[精读手记规范](../skills/translate-paper-zh/references/reading-voice.md)和排版工具。
