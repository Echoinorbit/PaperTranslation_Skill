# 科研论文的页边手记

读者已经在看论文。落笔的地方，应当值得在第二次翻到这一页时再看一眼。以下是 agy 为各类 Agent 定下的写法。它适用于一篇具体论文的阅读手记，翻译正文仍须保留作者原意。

## 先读懂作者怎么做研究

动笔前，先写下作者要回答的问题，找到文中最直接的一条结论，再追到使它成立的推导、观察、比较或引文。每处手记选一条合适的线索。同一篇论文也可能先证明性质，再在数据上考察它的效果。作者明说的理由可以直接转述，对其选择的推测用「我猜」「也可能」等措辞。

| 这一段如何得出结论 | 在原页上值得做的笔记 |
| --- | --- |
| 理论与证明 | 圈出结论依赖的假设和量词；找出用到该假设的第一步，抄一行等式或画一个满足条件的小例子。让符号的定义和适用域跟着推导走。 |
| 实地观测与统计实证 | 沿着测点、重复测量、聚合、比较的次序走一遍。给图中一个点标清实际代表的对象，核对单位、样本数、不确定性及结论能外推到哪里。 |
| 软件、模型与实验方法 | 从输入追到输出，区分继承的算法与本文的适配。遇到性能结论，再回查基线、控制条件和消融；遇到软件接口或科学工作流，则核对输入假设、转换步骤和验证方式。 |
| 综述、定性研究与论证 | 回查一个概括取自哪些材料。系统综述看纳入和排除，访谈看样本与编码，论证文章看前提、原始引文和可能的反例。用作者实际提供的证据限定措辞。 |

- **逆读实验。** 选一句具体结论，找到支持它的行、列或曲线，核对指标含义和方向。找出相比较的两组，说明哪些条件相同、哪些同时改变。多个因素一起改变时，结果能支持整套配置的比较；要解释某个部件的作用，再查更贴近这个问题的消融。如果论文没有这样的对照，就在相应范围内解读差值。
- **拆模型，也拆基线。** 沿输入、骨干、预测头、训练目标和输出追踪一个样本，优先讲清作者在哪一处做了改变。对关键基线，查它原来解决什么问题、本文采用哪个版本、怎样调整或取得结果。区分同协议重训、引用已有分数和直接比较外部产品。对照任务、数据划分、预训练、分辨率和测量口径中真正影响结论的差异。数据集论文则从观测缺口、参考标注和筛选规则追到评估范围。
- **沿文献核实出处。** 从本文实际的引文编号追到原创论文、官方方法或数据产品，核实作者、题名、年份和可访问的 DOI 或稳定链接。指出这篇文献解释哪个设计，本文的适配和数字仍指回本文的方法节、表行或附录。若同时有后续版本、未公开设置或矛盾记录，要交代能确认到哪一步。页边用少量原编号或短出处，优先引用能回答眼前问题的文献。
- **把关键公式讲给读者。** 说清它在证明、测量、预测或评价中的用途，说明变量来自哪里、对什么对象运算，以及关键一步怎样改变结果。遇到取平均、归一化、求差或取极值，按实际顺序讲，核对下标、分母、求和范围与单位。必要时用「取……」「假设……」代入一个合法例子，再回到作者真正用它的地方。原文省略的推导只能给出可核实的中间步骤。

页边优先写最容易卡住的一步，再在对应实验页接上验证。常规手记通常两到四短行，确实需要逐步解释的核心公式可用到约六行；按实际字宽试排。原文已经说清的基础知识可以留白，研究延伸放在读懂作者论证之后。

## 落笔的口吻

1. **直接写想到的事。** 看到什么方法选择、准备回哪张表、想试哪组对照，直接落笔。省去身份、分类标题和开场白。不同墨色给页面一点节奏，读者不用学图例便能读懂每句话。
2. **先顺着作者的证据走一遍。** 找到可指认的句子、实验、表行或图。写「想试……」前翻一下附录，看看作者是否已经做过。若做过，批注可以提醒读者两处合读，或者点出仍值得研究的差别。
3. **优先写研究方向和方法取舍。** 一笔只抓一个地方：为什么这样取样，两组实验是否可比，哪项假设换到别处就值得重验，什么观测能区分两种解释。公式也先看它怎样影响任务或结果的解释。每条通常两到四短行；一页、甚至整节都可以留白。
4. **让语气带出确定程度。** 已报告的结果可以写成陈述。未经验证的解释、改动和研究方向可写作「想试……」「换到……会怎样」「值得回头看……」。让读者看清条件，不虚构作者做过实验，也不替作者断言某个原因。
5. **整篇连起来读一遍。** 交替使用快记、比较、读表提示和真正想追问的问题。删去换篇论文仍可套用的评语、原句的同义复述，以及成串的审稿式问句。保留具体的研究对象、对照和可观察的结果。

在工作清单中保存物理页码、能唯一定位的已译词句或坐标，以及原文页、节、图或表。笔迹与旁批就近配对；来源可用一个简短的「表 2」「§3.4」。某项可复现性判断如果找不到原文根据，可以在工作清单中继续调查，也可以换一个更有把握、更有价值的点落笔。
