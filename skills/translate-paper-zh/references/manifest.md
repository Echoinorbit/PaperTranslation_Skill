# 翻译清单字段

`prepare` 生成的 JSON 包含原 PDF 文件名、术语映射和按原页顺序排列的 `pages`。页码从 1 开始。文本框坐标均为 PDF 点，以生成的源页左上角为原点。页图按 1.5 倍渲染，用截图像素量坐标时须除以 1.5。

`inventory.json` 的 `pages[].layout_hint` 随源页记录文字层状态（`text_layer`）、方向（`orientation`）、估计栏型（`layout`）、嵌入图片覆盖比例（`image_coverage`）和建议续排栏数（`flow_columns`）。`needs_layout_review` 提醒先看片，矢量绘制的图表和正文中的图内字仍需视觉盘点。正文与窄侧栏共存时可以按单主栏读，通栏图下的双栏另行核对；疑似三栏以上时可按语义转为单栏。人工确认的 `columns` 取 1 或 2，优先于自动建议，并允许旧清单沿用已有目标框。横向附表沿用该源页的方向。

每页包含 `page`、`visual_reviewed`、`items`，可指定 `columns` 为 1 或 2。每个条目的 `covers` 为对应源文本块 ID。原页内文字被拆成多块时可以合并，遇到跨页断词时可将相邻页的编号关联到同一句。一个块内有多段或被表题插入时，可以手动拆为多个条目，在第一个相关条目认领编号，其余条目保留正文并在目检时逐一核对。源图中有、文字提取时遗漏的图例也可新增条目。新增视觉内容可以没有源块编号。

真正的空白源页可令 `items` 为空，目检后同时设 `blank_reviewed` 和 `visual_reviewed` 为 true。脚本将另行验证该页渲染接近纯白。没有可提取文字的扫描页仍须识读其可见内容。

| 字段 | 用法 |
|---|---|
| `kind` | `heading`、`text`、`caption` 表示中文标题、段落与独立说明。`figure`、`table`、`formula` 表示裁自原文的对象。`keep` 表示应原样排印的书目、标识、原页标签或公式。 |
| `zh` | 拟排印的完整文字。对图表或公式，在此给出中文图表题、图例或公式说明，工具将它们与同一对象一起排版。 |
| `bbox` | 三种裁切对象必填。按 `[左, 上, 右, 下]` 精确圈住图表或公式，不包括相邻正文。源图中的英文章节正文不能作为插图裁入。 |
| `target`、`size` | 经过核对的原页目标框与名义字号。页面条目都有可用框时优先尝试原位排版。原位不可行时依次使用原栏内剩余空间、邻栏或紧接的下一页。无可靠目标框的页面按语义顺序重排。 |
| `caption_box` | 对原位图表和公式另给说明位置，须与图像和其他条目分开。将相关说明放在该对象的 `zh` 内。 |
| `emphasis` | 源文有独立的粗体问题或段首小标题时，另建条目并写 `"emphasis": "strong"`。章节标题会自动加重。相连的问句及回答按实际行高设置目标框和段距。 |
| `role` | 真实的出版页脚可标 `footer`，译文置于该源页最后一张译页的底部。 |
| `reason` | `keep` 必填，可用 `bibliography`、`identifier`、`page-furniture`、`formula`。 |

例如，若原表为图像而只有表题进入文本层，可以这样填写一个条目。坐标、源块编号和数字以实际论文为准。

```json
{
  "kind": "table",
  "bbox": [80, 120, 510, 245],
  "covers": ["p4b7"],
  "zh": "表 2　不同方法的分割结果（%）。列名依次为树木（Tree）、建筑物（Building）和平均交并比（mIoU）。"
}
```
