# 手稿字体

本目录保存三款完整静态字体，可离线排版卡其纸译文与手记。霞鹜文楷用于正文和笔记中需要辨清的数字、符号及技术标识，悠哉（Yozai）用于同页短句与中文旁批，Caveat 用于英文手记中的普通单词。PDF 导出时嵌入当篇使用的字形。随 Skill 分发字体时请保留各自的许可证。
