# 论文全文英译中

由当前 Agent 翻译和校对全文，默认交付一份中文精读手稿 PDF。撰写旁批前先读[精读手记规范](references/reading-voice.md)，同一规范适用于通过 Skill 或普通本地命令接入的 Agent。用户指定页码时可以制作选页样张，交付时写明原页范围。取一个新工作目录和新输出路径，保留输入文件。

## 取得原文和版面

使用 Python 3.11 或更新版及支持 `Page.clip_to_rect` 的 PyMuPDF。原图、公式和表格裁切使用该方法移除框外正文，避免搜索时出现重复段落。本项目实测 PyMuPDF 1.28.2。仓库开发环境可用 `.work/venv/Scripts/python.exe`。以下命令里的 `scripts` 相对于本 Skill 目录。

```text
python scripts/paper.py prepare paper.pdf paper-work
```

`inventory.json` 包含源文件校验值、逐页文本块和版面提示 `layout_hint`。`p001.png` 等图像显示实际版面，`translation.json` 是待填清单。完整论文省略 `--pages`，选页可加 `--pages 1-3,5`。

按每一页实际形态决定读序。先看方向、文字层可用程度、图片所占比例和推测的栏数，再对照页图。通栏标题下可能是两栏正文，首页窄侧栏也可能只有出版信息。混排、多栏和横向附表按区核对，优先给已确认的位置填 `target`。位置不可靠时，把语义条目按读序排好，用单栏或双栏续排。页图上的正文、脚注、标签都应在盘点之内。

无文本层、乱码、只有少量字或疑似扫描页，先从渲染页分区识读，能取得质量更好的同版 PDF 时也可换用。OCR 结果仍须与页图核对。看不清的页记录原页和范围，单独报告待核。预检清单标作 `preflight`；交付时从成品的排版报告核实 `excerpt`（选页）或 `full`（整篇范围），并逐页检查实际译文。

## 翻译并核对

先通读题名、摘要与相关方法段，按本文含义定术语。首次出现给中文和英文或论文使用的缩写，后续保持一致。模型名、数据集名、指标、单位、DOI、作者名及公式符号按原文保留。默认保留可检索的参考文献条目，用户要求时同时提供题名中译。

**保留作者判断的力度与适用范围。** 指明谁在什么条件下观察到什么。逐项对应肯定或否定、可能性、比较对象与方向、相关或因果，以及「总计」「每年」「仅在」「至多」等限制。中文需要多几个字才能说清这些关系时，保留限定词，让句子自然换行或续排。

**技术词译到原文给出的具体程度。** 以作者的定义、公式、表头和上下文确定译名。写入译文的方法、数据结构和处理步骤，都应能在相应原文中指出依据。遇到多义词或量词指向不清，先查文内定义和引用处。上下文仍不足时，用能保留原有解释空间的中文，必要时附原词。数字或单位在原文各处有出入时，各按原处保留，必要时用简短的「译注」指明两处位置。

交付前，挑出所有涉及判断强弱、比较、因果、数量范围和技术实现的句子，用源块编号定位完整原句，逐句与最终译文对读。跨栏、跨页时先接全句。试着在原句里指出译文中「更」「导致」「每」或某项具体实现各自对应的词，再反向核实原文的限定是否译全。遇到依据不足的表述，先改正文，有关段落重新排版后再复读。

| Open-Canopy 作者版的原文用词 | 忠实的中文写法 |
| --- | --- |
| 第 2 页，`particularly challenging` 与 `differs from typical natural image analysis settings` 分别描述难度和任务设定。 | 「从单幅影像预测林冠高度是一项颇具挑战的计算机视觉任务，其设定与典型的自然图像分析任务不同。」原句没有给两类任务的难度排序。 |
| 第 18 页，采集年份 `stored in the column lidar_year`。 | 「每个图块对应的激光雷达采集年份记录在 `lidar_year` 列。」文中提供的信息到列名为止。 |

编辑 `translation.json`，按真实阅读顺序填写段落、图、表、公式。每个源块编号由对应条目认领一次；同一完整句可引用相邻源页的编号。图像中的可见文字也须逐项审阅，即使提取清单没有列出。格式与排版字段见 [翻译清单](references/manifest.md)。

- 正文在原栏内自然换行。版面清楚时给出经原页核对的目标框。原位置装不下时让正文在相邻栏或续页顺读，保留原页标识。
- 保留提问、小标题及正文的层次。将有意加重的问句或段首标题标为 `emphasis: strong`；问句和回答分段且保持相邻。对同栏的连续文字按译后行高收紧段距，图、表和公式继续锚定原处。
- 将原图与中文图注、英文标签的中文释义合成一个条目。窄格、遥感分类色标、坐标轴及图例均提供对应中文。可以保留数值密集表的矢量或图像裁切，核实每行、每列都在裁切内，再逐项译出描述性表头。过大的对象按实际子图或完整表行分组，每组附对应中文。
- 用原公式裁切保存复杂显示公式。将成稿与原页同倍率放大，尤其核对 `≠` 的斜线、否定、上下标、向量箭头和重音；部分 PDF 将它们分为重叠字形。核对行内变量与编号。线性写法若会引起歧义，保留清晰的原式。记录公式引用与原编号。
- 完成该页的文字与视觉核对后设置 `visual_reviewed`。图中无法辨认的标签、仍有英文的正文、遗漏的脚注均属于待处理项。

## 出版与验收

```text
python scripts/paper.py render paper.pdf paper-work paper-work/reviewed.pdf --notebook-paper
```

脚本拒绝遗漏源块、重复认领、无效裁切和未完成巡检的正式输出。`--preview` 可生成带校对标识的草样。源块完整只是结构检查，还须看最终 PDF。对照各页原图及输出，按 `.qa.json` 的页码映射检查读序、页末续接、图注位置、表格行列、公式和缺字。连续页上不能只有脱离对象的图例或悬空页脚。若有遗漏或错排，修清单、在新路径重新生成，直至通过。全文交付先核对报告中 `scope` 为 `full`，并说明仍未解决的具体问题。

## 生成精读手稿

将通过校对的中文底本保存在工作目录内，用它定位批注。默认交付一份卡其纸中文精读手稿。上一步的 `--notebook-paper` 把可搜索的中文正文直接排在纸色上，单独保留原图、表、公式及其底色。若用户指定白纸普通译文，生成底本时省略该选项，校对后即可交付。

通读论文后，从一个关键结论倒查它成立的理由。理论论文可以回到假设和证明中关键的一步，观测研究可以追到取样单位、测量和比较，软件或方法论文可以画出输入到输出的转换，综述可以追到文献的纳入依据。出现模型、基线或消融时再具体拆解。论文在不同段落采用不同论证方式时，手记随段落切换。对关键公式讲清运算顺序及其在本文的用途。研究设想用自然的假设或问句表达。[跨学科精读手记规范](references/reading-voice.md)

把摘要的承诺、正文实际检验的命题和结论的措辞并排读，再选值得落笔的关系。方法和结果互相回指，写出一项对照能回答什么；段落次序、转折、设问或动词影响论证时，把具体词句及其效果点出来。明确区分作者的理由与读者据文作出的解释。删去仅把正文换词重说的旁批。[论证与行文的读法](references/reading-voice.md#先沿着作者的论证读一遍)

优先在原段落、公式或表行附近的留白落笔。一行短句就能解释的，写在原页内；方法有先后时就近画两三步，用到对照时可以抄一个带表头和单位的小表。较长的研究思考接在同页外侧。用 `--uniform-margin` 统一纸宽，允许普通页整页留白。重开成品，从圈住的词或数值顺着笔迹读一遍，确认箭头和字都避开正文、图例与表内数字。再抽查全文可提取、彩色影像底色与数据图一致。[手记清单字段与示例](references/reading-notes.md)

中文译文用黑色霞鹜文楷，手记用笔画较粗的悠哉 Medium，普通英文手记用 Caveat。数字和含数字的技术标识用易辨的正体。三款字体随 Skill 提供，PDF 嵌入用到的字形。常用蓝墨写方法，红笔可圈值得回看的差别，浅黄荧光下保留原字，配深琥珀色手写字。缩到整页或转为灰阶后，仍应看清笔迹所指的位置。[字体与许可](assets/fonts/README.md)

```text
python scripts/annotate.py paper-work/reviewed.pdf paper-work/notes.json paper.zh-notes.pdf --uniform-margin --notebook-paper
```
